險中求生｜城市任務與風險管理 v8.2

本版採「工作加錢、事故扣錢、財產排名」，將保險操作簡化，並恢復自動定時出題。
程式放在 GitHub 分支 codex/traffic-game-v8.2 的根目錄；此交付分支不等於目前 main 的網站已更新。

【遊戲流程】
1. 選車輛、職業與任務，再一眼選擇保障：
   不投保（違規）$0：沒有強制險或財損保障。
   只保強制險 $600：符合條件的受害人人身保障，不賠車損、財損。
   強制＋財損 $1,800：再加第三人財損與自己車損的教學綜合方案。
   額度與細節收在可展開說明內；出發後不必看保單或分配支付來源。
2. 選幹道、巷道或慢行路線；行車中改道在下一個路口生效。
3. 完成工作取得該職業的收入，發生事故則依出發前的保障自動試算自付費用。
   現場仍需先確認安全、通報、拍照、整理文件；文件完成即自動結算與恢復行車。
   沒有理賠選擇題或費用分配下拉選單，保險不會降低撞車機率。
4. 排行榜與前三名只比較目前財產：
   起始財產－方案支出＋完成工作收入－事故自付－未投保模擬罰款。
   答題與安全行車不再累積分數，也不憑答題加錢；答題用來學習與檢視觀念。
5. 每局預設5分鐘「行車時間」，答題暫停計時，行車時間用完自動結束。
   老師仍可提早結束；若提早結束，本金高的職業自然較有利。
6. 每行車25～30秒自動出一道全班案例題，答題12秒、公布解析4秒後自動恢復行車。
   全程不需要老師按出題、公布或繼續；老師可視課堂需要提早公布或繼續。
   全班案例不會被算成玩家事故，也不會扣錢。個人事故處理在全班題期間暫停。
7. 老師可指定學生進行不扣款的「處置演練」，用來熟悉操作。
   真正行車事件才計入事故帳本；演練時其他學生繼續任務。


【事故後查驗強制險】
本遊戲沒有獨立隨機臨檢：事故發生後，先確認安全，再「通報並查驗保險」。
未投保者此時扣一次模擬罰款 $3,000；已投保強制險者沒有這筆罰款。
之後拍照、整理文件，由出發前鎖定的方案自動結算應付損失。
範例：本案例汽車事故未投保，自付損失 $8,500＋模擬罰款 $3,000，共 $11,500。
只保強制險時，自付財物損失 $6,500，沒有未投保罰款。
同一事故重送操作不會重扣；處置演練、全班題均不實際扣款。
若故意不處理事故，局末仍會查驗並結清已發生的損失與罰款，再依財產排名。
局末清算保留未完成處置的紀錄，不會假裝玩家已完成安全、通報或蒐證。
上述保費、罰款與損失都是遊戲金額，不是現行法定罰鍰。
現實未投保也可能在事故以外查獲；受害人的其他法定救濟並非因駕駛未投保就消失，
本遊戲只模擬駕駛應負費用，實際給付、賠償及追償仍依法與事故事實判斷。

【職業差異與平衡】
職業                 起始財產    每站完成工作收入    每份工作最低行車時間
上班族                10,000          430                18秒
外送員                 6,000          530                12秒
家庭照顧者            11,000          500                26秒
業務人員               8,000          670                22秒
學生                   6,500          510                14秒
教師／公務人員        10,500          500                24秒

低本金配較快收入，高本金配較慢收入；停車速度0不會累積工作行車時間。
每份工作仍要實際抵達目的地；路程、號誌與事故可能讓完成時間更長。
基準測試：5分鐘有效行車、晴天暢通、40km/h、幹道、無事故、無其他車壅塞，
不含保費及罰款，6職業×12起點共72次模擬，期末財產約15,540～16,190，差距約4.18%。
這是基準平衡，實際選路、投保、多人壅塞與事故會改變結果，並不保證每局相同。

【本機試玩】
不要直接雙擊HTML；請在本資料夾啟動靜態伺服器：

  python3 -m http.server 8010 --bind 127.0.0.1

用瀏覽器開啟伺服器首頁index.html，點「開啟試玩教師端」。
1. 建立四位數房號，點「開啟學生試玩分頁」。
2. 在同一瀏覽器的學生分頁填姓名、選車輛、職業、任務、保障與路線，再準備完成。
3. 可再開另一個學生分頁；老師點「全員發車」。
4. 學生完成工作、觀察財產排行。約25～30秒行車後會自動出題。
5. 要立即熟悉事故操作，老師選學生後點「指定學生處置演練」（不扣款）。
6. 五分鐘行車時間到會自動結束，可查看財產帳本；重設後學生須重新加入。

本機試玩只在同一裝置、同一網站來源、同一瀏覽器設定檔的分頁同步，不讀寫正式Firebase。
請允許localStorage，使用支援Web Locks的新版Chrome/Edge等瀏覽器。
教師分頁需保持開啟；強制結束瀏覽器程序不保證即時更新在線狀態。

【正式部署】
交付分支另提供 release-files/traffic-game-v8.2.zip：解壓後網站檔案就在最外層。
要更新既有 main 根目錄網站，請上傳這些檔案到 main 根目錄；不要只上傳外層資料夾。
若只更新交付分支，main 的線上網站不會自動切換版本。

將本資料夾全部網站檔案一起更新，不能只更新HTML：
  index.html
  teacher.html / teacher-core.js / teacher-v8.js / teacher-v8.css
  student.html / student-core.js / student-v8.js / student-v8.css
  bootstrap.js / risk-engine.js / local-backend.js
  game-data.js / firebase-config.js

檔名保留v8以便原有部署直接更新；畫面版本與快取為8.2/820。
firebase-config.js保留原設定。正式模式由首頁「開啟線上教師端」進入，不加demo=1。
需啟用Firebase匿名登入及Realtime Database，規則需允許本版新增的玩家／題目欄位。
SDK來自www.gstatic.com，QR Code來自cdn.jsdelivr.net；另需資料庫與匿名驗證端點。
tests/、artifacts/、README.txt及教師題庫文件不必上傳。
GitHub交付不是網站部署，不會改動正式Firebase資料。
