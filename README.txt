險中求生｜城市任務與風險管理 v8.4

本版採「工作加錢、事故扣錢、財產排名」，保留簡單保險選擇，定時出題後由老師控制公布與繼續。
程式放在 GitHub 分支 codex/traffic-game-v8.4 的根目錄；此交付分支不等於目前 main 的網站已更新。

【遊戲流程】
1. 選車輛、職業與任務，再一眼選擇保障：
   不投保（違規）$0：沒有強制險或財損保障。
   只保強制險 每5題一期 $250：符合條件的受害人人身保障，不賠車損、財損。
   強制＋商業 每5題一期 $750：再加第三人財損、自己車損及明列的駕駛人傷害保障。
   額度與細節收在可展開說明內；每5題重新選擇，不需要手動分配理賠來源。
2. 選幹道、巷道或慢行路線；行車中改道在下一個路口生效。
3. 完成工作取得該職業的收入，發生事故則依出發前的保障自動試算自付費用。
   現場仍需先確認安全、通報、拍照、整理文件；文件完成即自動結算與恢復行車。
   沒有理賠選擇題或費用分配下拉選單，保險不會降低撞車機率。
4. 排行榜與前三名只比較目前財產：
   起始財產－方案支出＋完成工作收入－事故自付－未投保模擬罰款。
   答題與安全行車不再累積分數，也不憑答題加錢；答題用來學習與檢視觀念。
5. 每局預設5分鐘「行車時間」，答題暫停計時，行車時間用完自動結束。
   老師仍可提早結束；若提早結束，本金高的職業自然較有利。
6. 每行車25～30秒自動出一道全班案例題。學生作答沒有倒數或逾時限制。
   老師按「公布答案」後可持續講解，直到按「繼續行車」才關閉題目並恢復行車。
   思考、答題及講解期間，五分鐘行車局時計時均暫停；沒有12秒作答或4秒自動關閉。
   全班案例不會被算成玩家事故。每完成5題，保險到期並進入續保選擇；答題與續保期間均暫停局時計時。
7. 老師可指定學生進行不扣款的「處置演練」，用來熟悉操作。
   真正行車事件才計入事故帳本；演練時其他學生繼續任務。


【每五題續保與費用平衡】
以全班已公布且按「繼續行車」完成的題目計數，每5題進入下一保期；
不按個人答對率計數，未作答也不會延長舊保單。
學生每期重新選擇不投保／強制險／強制＋商業；畫面不預選，按確認才扣費。
每個保期開始時，保費用以下公式報價（遊戲幣）：
  強制險600或商業1800 × min(125秒,剩餘行車秒數) ÷ 300秒，無條件進位。
標準一期為$250／$750；最後一段不足125秒就減收。
例：只剩25秒，本期強制險$50、商業$150；不投保一律$0。
依正常每25～30秒出題、每局5分鐘行車設定，連續同一方案的總保費
最多仍是原本強制險$600、商業$1,800；老師多講解不會增加保費。
不同職業用相同報價；保費不因學生答錯、收入高低或開車快慢而增加。
續保不會卡死遊戲：老師可等大家選完，再按續保畫面的「繼續行車」。
若老師提早繼續，按鈕明示未回覆者視為「不投保」，不會默默替學生買保單。
同一保期重送確認不重扣；保費累計列在帳本，財產不足仍可呈現負值並工作回復。
舊事故固定採事故發生時的保單；新續保不能回頭理賠先前已發生的事故。

【教師投影字體】
全班題目預設放大為32px；題目旁提供A−、A＋、滑桿、24～64px數值輸入及重設。
背景敘述、選項、解析會一起縮放，長文字換行、畫面可捲動，不會截掉選項。
字體偏好由教師瀏覽器記住，不影響學生手機字體或作答狀態。

【事故後查驗強制險】
本遊戲沒有獨立隨機臨檢：事故發生後，先確認安全，再「通報並查驗保險」。
未投保者此時扣一次模擬罰款 $3,000；已投保強制險者沒有這筆罰款。
之後拍照、整理文件，由出發前鎖定的方案自動結算應付損失。
損失會隨機產生：對方人損、我方人損、對方財損、我方財損可單獨或複合出現。
每次至少一類，最多四類；金額也隨機。不同保障會留下不同的自付費用。
只保強制險不賠財物，也不會把單車自撞駕駛本人的傷害列入自己的強制險。
第三方案明列附加駕駛人傷害保障，並不代表所有商業險都有這項保障。
同一事故重送操作不會重扣；處置演練、全班題均不實際扣款。
若故意不處理事故，局末仍會查驗並結清已發生的損失與罰款，再依財產排名。
局末清算保留未完成處置的紀錄，不會假裝玩家已完成安全、通報或蒐證。
上述保費、罰款與損失都是遊戲金額，不是現行法定罰鍰。
現實未投保也可能在事故以外查獲；受害人的其他法定救濟並非因駕駛未投保就消失，
本遊戲只模擬駕駛應負費用，實際給付、賠償及追償仍依法與事故事實判斷。

【隨機個人事故】
超速仍會觸發失控事故；即使維持安全參考速度，也有突發路面異物、自失控或碰撞風險。
系統每15秒檢查一次個人行車風險：幹道基準14%、慢行9%、巷道20%，
守規速乘0.75，雨天再乘1.35，最高40%；這些是教學遊戲機率，不是實際道路統計。
起步保護、事故後冷卻、速度0及停站處理時不觸發；投保與否不改變事故機率。
個人事故中的「自失控」也可能波及路人或他人財物，畫面會依實際抽到的損失顯示。
隨機事故不是保證每名玩家必定出事，守規速會降低風險但不會降為零。
本遊戲只模擬本次應付費用，若涉及對方保險或其他補償，實際仍須另判斷請求途徑。

低本金配較快收入，高本金配較慢收入；停車速度0不會累積工作行車時間。

基準測試：5分鐘有效行車、晴天暢通、40km/h、幹道、無事故、無其他車壅塞，
不含保費及罰款，6職業×12起點共72次模擬，期末財產約15,540～16,190，差距約4.18%。
這是基準平衡，實際選路、投保、多人壅塞與事故會改變結果，並不保證每局相同。

【本機試玩】
不要直接雙擊HTML；請在本資料夾啟動靜態伺服器：

  python3 -m http.server 8010 --bind 127.0.0.1

用瀏覽器開啟伺服器首頁index.html，點「開啟試玩教師端」。
1. 建立四位數房號，點「開啟學生試玩分頁」。
2. 在同一瀏覽器的學生分頁填姓名、選車輛、職業、任務、保障與路線，再準備完成。
3. 可再開另一個學生分頁；老師點「全員發車」。
4. 學生完成工作、觀察財產排行。約25～30秒行車後會自動出題，老師手動公布與繼續。
5. 要立即熟悉事故操作，老師選學生後點「指定學生處置演練」（不扣款）。
6. 五分鐘行車時間到會自動結束，可查看財產帳本；重設後學生須重新加入。

本機試玩只在同一裝置、同一網站來源、同一瀏覽器設定檔的分頁同步，不讀寫正式Firebase。
請允許localStorage，使用支援Web Locks的新版Chrome/Edge等瀏覽器。
教師分頁需保持開啟；強制結束瀏覽器程序不保證即時更新在線狀態。
