險中求生｜城市任務與風險管理 v8.0

這是以上傳的 v7.35 為基礎製作的可試玩改版；原始上傳檔案未被覆蓋。

【這次改了什麼】
1. 學生出發前，以 $10,000 虛擬預算選擇保障；強制險基本人身保障已含在設定中。
   基本保障：額外方案費用 $0；責任補強：$1,200；車損補強：$2,800。
   保障準備完成後鎖定，不能在事故發生後補買。保險不會降低事故機率。
2. 幹道、巷道、慢行三種路線會影響實際導航、速度與相對事件風險。
   行車中可以改道，下一個路口生效；估計到達時間不含號誌及臨時停車。
   保留自動行車，學生不需要操作方向盤。
3. 每站取得 $300 任務收入，帳本記錄方案支出、保障分擔及自行負擔。
4. 個人事故只讓當事人的車停下；依序確認安全、通報、拍照、整理文件。
   目擊者資料為可選補充，不能自動決定責任。
5. 文件完成後安排醫療、第三人財物、自己車損的支付來源，顯示逐筆結算。
   結算以單一交易更新，重送指令不會重複扣款。負餘額仍可完成任務賺取收入。
6. 移除固定每 30 秒強制事故／全班停車答題。
   一般事件與路線、速度、天氣有關；超過危險超速界線可能觸發護欄事故。
   老師可手動開啟「全班案例演練」，保留原有題庫作討論。
7. 老師可指定學生進行「處置演練」，用來熟悉操作；明示不扣款、不計事故。
   真實遊戲事件才計入帳本；其他同學可繼續行車。
8. 賽後顯示本局風險管理帳本；手機版支援單欄操作及事件自動捲動。

【立即在本機試玩】
請使用靜態網頁伺服器，不要直接雙擊 HTML（file:// 不支援此試玩流程）。
在解壓後的資料夾執行：

  python3 -m http.server 8010 --bind 127.0.0.1

在瀏覽器開啟伺服器首頁的 index.html，點「開啟試玩教師端」。
1. 建立四位數房號。
2. 點頂端「開啟學生試玩分頁」，在同一瀏覽器完成姓名、車輛、職業、任務、速度及保障選擇。
3. 可再次開啟另一個學生分頁加入；每個分頁有獨立身分。
4. 老師點「全員發車」，學生試著改道，觀察老師地圖與任務收入。
5. 老師選一位學生，點「指定學生處置演練」，學生操作現場工具及費用分配。
6. 真正事故依遊戲行車條件觸發；處置演練僅教學試作，不改變學生財務。
7. 老師可開啟「全班案例演練」、公布解析，再繼續任務。
8. 結束本局查看帳本；重設會請學生重新透過邀請加入。

本機試玩採瀏覽器 localStorage，在同一裝置、同一網站來源、同一瀏覽器設定檔的分頁同步。
試玩完全不讀寫正式 Firebase。請允許本機儲存，使用新版 Chrome / Edge 等支援 Web Locks 的瀏覽器。
本機頁面關閉事件採盡力通知，強制結束瀏覽器程序不保證立即更新在線狀態。

【正式課堂部署】
將以下網站檔案一起放到 GitHub Pages 專案根目錄，不能只更新 teacher.html/student.html：

  index.html
  teacher.html / teacher-core.js / teacher-v8.js / teacher-v8.css
  student.html / student-core.js / student-v8.js / student-v8.css
  bootstrap.js / risk-engine.js / local-backend.js
  game-data.js / firebase-config.js

firebase-config.js 保留原上傳設定；正式模式使用 Firebase compat SDK 10.12.5。
從首頁「開啟線上教師端」進入，不加 demo=1。學生使用老師產生的邀請連結／QR Code。
原有 Firebase 匿名登入及 Realtime Database 必須可用，且需檢查規則是否允許本版新增欄位。
Firebase SDK 使用 www.gstatic.com；QR Code 使用 cdn.jsdelivr.net；Realtime Database 需要既有設定中的資料庫網域。
教師關閉／重新整理頁面會使原房間失效；保持教師分頁開啟。

tests/、artifacts/、README.txt、教師用_精選32題題庫.txt 不影響網站執行，不必上傳。
GitHub 新分支用於交付本版程式；這不代表已部署網站，也不會更動正式 Firebase 資料。

【驗證方式】
規則與本機同步層測試（Node.js 24）：

  node --test --test-isolation=none tests/*.test.cjs

完整瀏覽器測試（測試環境需 Node.js、Playwright 及 Chromium；先啟動上述伺服器）：

  node tests/browser-smoke.cjs

若 Chromium 不在 /usr/bin/chromium，可用 CHROMIUM_PATH 指定執行檔。
Playwright 須可由 Node 載入；瀏覽器測試只使用本機試玩模式，會阻擋任何外部請求。
測試包含教師與兩名學生、出發保費、實際選路、事故步驟、保障缺口、重複結算、
演練不扣款、任務收入、手動全班案例、390px 手機版、結束停用及房間重設。
截圖輸出到 artifacts/。

【教學設定邊界】
保費、金額、額度、風險與速度數字皆為遊戲模擬，不是保險商品報價或實際道路速限。
個人碰撞案例明示事故責任、傷者資格及承保假設；超速護欄案例不模擬傷者醫療費。
實際給付應依法律、受害人身分、事故責任及契約條件判斷。
已驗證本機完整互動；正式 Firebase 跨裝置多人連線仍需部署後小規模試課。
